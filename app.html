GroupWhy

Type a number the way you see it written. See what 33 locales think it means: which character they use to group digits, which for decimals, and the value they read.
Separators come from your browser's Intl (CLDR) locale data, so a different browser version can show different symbols. This is a strict reader: only that locale's own group and decimal characters (plus matching space and apostrophe variants) are accepted, so "1.5" is invalid in German instead of being guessed. Many real apps are more lenient. Digit systems: only each locale's default digits are read (Arabic-Indic for ar-EG). Not covered: currency symbols, percent, exponent form. Runs in your browser; nothing is uploaded.
